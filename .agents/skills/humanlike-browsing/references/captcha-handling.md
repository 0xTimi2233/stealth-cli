# 质询状态解离策略

根据页面安全质询类型执行针对性解离动作与阻断判定，确保操作具备明确的自愈与退出闭环

## 质询分类与处理

### 1. 轻量交互质询

适用于 Cloudflare Turnstile 或类似单击式真人验证：
- 识别特征：页面主操作按钮处于禁用状态，且存在验证复选框
- 执行动作：定位复选框引用执行 `click <checkbox_ref>`，随后执行 `snapshot -i` 检查目标按钮状态；若尚未完成，间隔执行 `snapshot -i` 复验至多两次
- 判定基准：目标操作按钮解除禁用即判定解离成功；若出现报错标识或按钮持续禁用，停止重试并报告阻断原因

### 2. 字符图形验证码

适用于包含噪点、干扰线或扭曲字符的图片验证码：
- 识别特征：页面包含验证码图片元素与关联的文本输入框
- 执行动作：
  1. 定位验证码图片元素执行 `screenshot` 获取局部图像
  2. 多模态解析图像中的字母与数字文本
  3. 执行 `click <input_ref>` 聚焦输入框，执行 `keyboard type "<text>"` 填入解析结果
  4. 触发校验或提交
- 判定基准：若页面提示验证码错误，执行刷新验证码图片，重新识别并输入一次；连续两次失败则停止操作并转交人工

### 3. 复杂行为质询

适用于拼图滑块与九宫格图像多选质询：
- 识别特征：页面弹出要求拖动滑块对齐缺口，或要求在图片矩阵中点选特定目标物体
- 判定基准：复杂行为质询依赖连续高频轨迹采样与多轮交互判定，离散命令行工具无法提供确定性通过率；禁止在无专用轨迹算法支持下盲目重试
- 处置流程：立即执行 `screenshot` 保存当前质询现场，提取界面错误文案回传，终止当前操作并明确报告需人工介入
